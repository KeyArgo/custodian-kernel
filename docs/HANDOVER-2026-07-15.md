  5. `talaria/policy.py`: kernel-grade guards (`self_protection`/`prompt_injection`/`secret_leak`) were actually disableable via `policy.yaml` despite the module docstring's explicit promise they "cannot be disabled by policy."
  6. `talaria/policy.py`: PII redaction was silently dead on **every fresh install** — `redact: []` (the shipped default) caused the guard to never be added at all, even with `pii: true`.
  7. `talaria/policy.py`: a malformed `guards:`/`tools:`/`paths:` value (e.g. `guards: true` instead of a mapping) crashed the whole compiler before any guard — including the kernel-grade ones — was added.

### 6. Broker naming — finalized to **Custodian Paladin**
Every candidate checked via WebSearch before deciding, not just asserted:
- **Citadel** — rejected. Infamous credential-stealing banking trojan malware (11M infections, $500M+ losses, FBI takedown) — the worst possible association for a credential-protection product.
- **Aegis** — direct collision (Aegis Authenticator, a popular open-source 2FA vault app; a separate Aegis Password Manager).
- **Paladin** (bare) — strong collision (PALADIN forensics toolkit, "most popular forensic suite in the world," government/military users) — but survivable **with** the "Custodian" prefix, since the function (forensics vs. credential broker) is genuinely different.
- **Garrison** — real collision (Garrison Technology, a substantial defense-grade cybersecurity company, acquired by Everfox) — survivable with the prefix for the same reason.
- **Keep** — risky even with the prefix: Keeper (a major password manager) is phonetically close and in the *same* category.
- **Rampart** — rejected even with the prefix: Microsoft has an open-source tool literally named RAMPART for securing AI agents (released ~2 months prior), plus a commercial Rampart-AI product with near-identical positioning to Custodian's own pitch. The one collision in this whole search that's in Custodian's own category.
- **Custodian** (the top-level name itself, already shipped) — checked too, since the user asked directly. Bare `custodian` PyPI name is already taken (`materialsproject/custodian`, 2.5M downloads) — this is why the package is `custodian-kernel`. Closer conceptual collision: Cloud Custodian (CNCF Incubating, YAML policy/governance engine). No malware association. Judged survivable, normal brand crowding — not renamed, since it's already live across PyPI/GitHub/a hackathon entry.

User selected **Custodian Paladin**.
