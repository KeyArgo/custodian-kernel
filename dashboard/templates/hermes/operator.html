Demo Script — run steps in order
  1. Step 0 — Earn $1,200 — Shows revenue in. No band, no approval, no cap. Earning is always unrestricted by design.
  2. Step 1 — Spend $85 autonomously — Within the agent's authority band → executes with zero human input. Copy the PaymentIntent ID from the output — you'll need it for Step 7.
  3. Step 2 — Request $3,500 — Exceeds the band. System escalates and sends a real SMS to the operator's phone. The code appears in the mockup below — judges can see it on screen.
  4. Step 3 — Approve with the SMS code — Enter the 6-digit code shown in the mockup (same code sent to the operator's real phone). Money moves only after a real human enters it.
  5. Step 4 — Engage kill switch — Absolute override. No band, no approval, no exception can bypass it.
  6. Step 5 — Prove kill switch blocks everything — Try a normally-fine $40 spend. Gets denied outright. The AI cannot override this.
  7. Step 6 — Release kill switch — Normal evaluation resumes.
  8. Step 7 — Refund $85 — Paste the PaymentIntent ID from Step 1 output (starts with pi_3...). Refunds always escalate — there is no autonomous refund path by design.
  9. Step 8 — Approve the refund — Second SMS code from your phone. Refund executes only after human approval.
