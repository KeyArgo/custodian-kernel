## What changed (commit a20f61c on feat/confined-bubblewrap-beta)

Move: claude/codex/hermes/opencode harness guards moved from
custodian.{claude,codex,hermes,opencode}_guard/ to custodian/guards/{claude,codex,hermes,opencode}/
(consolidated). Thin sys.modules re-export shims at the OLD paths so
existing imports, `python -m custodian.claude_guard.hook` hook wiring,
and console scripts keep working.

New: custodian.guards.gate module — single state file
(~/.custodian/guards.json) every surface reads and writes. Atomic tmp
replace, corrupt-file fall-back to dormant, no split-brain between
Hermes and the terminal.

New CLI: `custodian guards {enable,disable,status} <name>` for
codex|claude|hermes. The status output is plain text; no JSON or flags
required.

Installer: new flags `--with-codex`, `--with-claude`, `--with-hermes`
that map to `custodian guards enable <name>` after install.
