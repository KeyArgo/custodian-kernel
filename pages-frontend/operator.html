Self-Verify — the API is public, you can hit it from your own terminal

  
These commands work right now against the live system. Each one creates a real Stripe PaymentIntent, returns a real ID, and appears in the live activity feed above.


  
1. Earn $0.50 (no band, no cap, no approval)

  
curl -X POST https://getcustodian.xyz/api/v1/operator/earn \
  -H "Content-Type: application/json" \
  -d '{"amount":"0.50","description":"judge self-test: earn"}'

  
  


  
2. Spend $0.50 (autonomous, within L2 band)

  
curl -X POST https://getcustodian.xyz/api/v1/operator/spend \
  -H "Content-Type: application/json" \
  -d '{"amount":"0.50","description":"judge self-test: spend"}'

  
  


  
3. Refund the PaymentIntent from step 1 or 2 (always escalates to Twilio SMS)

  
curl -X POST https://getcustodian.xyz/api/v1/operator/refund \
  -H "Content-Type: application/json" \
  -d '{"payment_intent_id":"pi_xxx","amount":"0.50","description":"judge self-test: refund"}'

  
Replace pi_xxx with a real ID from the live activity feed above. Refunds always require a human approval code via Twilio.
