## The ecosystem (all code-reviewed this week except where noted)

- iron-proxy (ironsh, Apache-2.0, Go, 552 stars, 5 months): MITM egress proxy, default-deny, dial-time CIDR deny, proxy-token→secret swap at egress, per-request audit. Weaknesses: bypassable unless routing enforced; bearer tokens; RFC1918 not denied by default; audit not tamper-evident. Removed its own token broker (June 2026) — no decision layer by design.
- NVIDIA OpenShell (Apache-2.0, Rust, 8k stars, alpha): sandbox runtime for agents (Landlock/seccomp, Docker/Podman/K8s/MicroVM), declarative YAML policy, gateway. Weaknesses: Landlock defaults BestEffort (alerting ≠ containment); empty policy = no restriction; driver-dependent isolation; policy-complexity foot-gun.
- NVIDIA NemoClaw (Apache-2.0, TypeScript, 22.1k stars, very active): runs Hermes/other agents inside OpenShell with managed inference. The off-the-shelf Hermes↔OpenShell bridge (hermes topic first-class).
- cyberware (rhCat, MIT, alpha): governance runtime — agent proposes, nothing runs except through it; hash-pinned steps, value-free wire, tamper-evident provenance ledger, govd server + fleet plane. Same plane as custodian (control layer). Source NOT yet reviewed by us (README-level only). Roadmap already plans adopting its govd sidecar + Rust verifier post-0.5.0.

## The agreed architecture (handover doc filed)

Three orthogonal layers: OpenShell (runtime isolation) + iron-proxy (network boundary) + custodian/Paladin (authority: vault outside sandbox via per-run UDS, harness guards, L0-L4, oracle verification, receipts; custodian mints proxy tokens). cyberware = same plane as custodian (adoption path: govd/verifier into custodian). Secret flow: real secrets only in Paladin vault + iron-proxy secret source; agent holds tokens + grants. Staged build: Stage 1 = custodian+Hermes guard (done, launch-ready); Stage 2 = + iron-proxy (token seam, egress forcing); Stage 3 = + OpenShell (NemoClaw proposed as default driver for Hermes launch, with a swappable driver seam and a knob-verification item: does NemoClaw expose Landlock hard_requirement + egress forcing?).
